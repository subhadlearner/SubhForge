# InsightForge → SubhForge learning ledger

Source project: [InsightForge](https://github.com/subhadlearner/insightforge-agent)

This ledger starts **without asserted lessons**. Following each completed InsightForge ticket, record only transferable lessons backed by evidence. A ticket with no meaningful lessons leaves this file unchanged; the review outcome can be reported in conversation.

## Entries

_No lessons have been individually assessed and approved for this ledger yet._

When the first lesson qualifies, replace the placeholder with an entry using this template:

### IF-L001 — Concise finding

- **InsightForge ticket / milestone:** Link to issue and closed PR
- **Observation (verified):** What actually happened, with precise scope
- **Evidence:** Links to commits, tests, metrics, logs or review decisions
- **Interpretation / root cause (hypothesis if unverified):** Why this may have happened
- **Transferable lesson:** What could generalize beyond InsightForge
- **Proposed SubhForge application:** Relevant workflow, requirement, readiness or qualification area; no implied approval
- **How to validate:** Evidence or scenario that would support or disprove adoption
- **Decision status:** Proposed / validating / adopted via approved change / rejected / deferred
- **Related SubhForge decision:** Link when one exists

Assign sequential IDs and do not reuse retired IDs. Avoid repeating observations across entries; amend an existing entry when appropriate.
